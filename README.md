# XpBottle Grabber

XpBottle Grabber is a server-side mod for collecting experience in bottles.
This mod allows you to create experience-level bottles, just like regular experience bottles.

<img width="486" height="374" alt="Main Gui" src="https://github.com/user-attachments/assets/78ecc68c-373c-4207-a578-739d0ee98ebb"/>

## Features

- Convert XP into bottles
- Shift-click to create multiple bottles
- Predefined level bottles: 15, 30, 50, 100
- Store XP in bottles (NBT)
- Retrieve XP by using the bottle

<img width="402" height="154" alt="Demostration" src="https://github.com/user-attachments/assets/8dcca4b0-c130-481d-b47f-2a3418976f53"/>

Gui open via command `/xpbottle`

Controls:
- Left click — create one
- Shift + click — create maximum

## Mechanics
- Uses vanilla XP formulas (0–16, 17–31, 32+)
- Requires glass bottles
- Drops items if inventory is full
